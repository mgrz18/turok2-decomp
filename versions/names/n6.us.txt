// N2 part n6: functions at 0x00290000-0x002AFFFF (libaudio, libultra, libc, the
// SN debugger host I/O, Acclaim's audio decoder). Most of this range is
// libultra / libaudio linked in the same order as in Turok: Rage Wars:
// thejunkman9000's symbol_addrs.txt (references/rw_junk) names the same
// functions in the same order with the same sizes, and decompals/ultralib gives
// the canonical names. Where a run of small same-sized API wrappers made the
// order ambiguous, the code itself decided (event type constants, hardware
// registers, the handler a ...New function installs). Names already in
// versions/names.us.txt are not repeated.
