// Only 5 are named. Everything from 0x800A51E0 up is the engine .rodata (code_rodata, linked from
// 0x800A51F8 in KSEG0, plus the string tail of .code at 0x800A51E0): float literal pools (also the ones
// declared as Tuning / Unk800A71A8 / Unk800A7990 / func_8020CA10_G1 structs, which are just the pools
// seen through a struct to keep the load order), CCache__Request description strings ("anim object
// info", "simp geometry", "level index"...), a {0,1,0} CVector3 initializer and jump tables. Those should
// become literals in C, so they are skipped.
